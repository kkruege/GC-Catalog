# GC Spring 2027 Course Browser

Every Spring 2027 course we could find across CUNY Graduate Center programs, gathered in one place, with full descriptions, professors, and meeting days and times. It also has a weekly calendar view and the course requirements for each GC certificate and the Psychology methods concentrations.

**Live site:** https://kkruege.github.io/GC-Catalog/

This is a student project for the [GC AI-Assisted Coding Class](https://www.gc.cuny.edu/digital-humanities/curriculum-and-degree-information/courses#fall-2026). It is not an official Graduate Center site. This site was built with AI assistance, and some information may be incorrect or out of date. AI can make mistakes, for example matching a description to the wrong class. Always confirm details on CUNYfirst and with each program before you register.

## Sources

- [CUNY Global Class Search](https://globalsearch.cuny.edu/CFGlobalSearchTool/search.jsp), collected November 14, 2026
- Graduate Center department and program web pages
- The Psychology program's Spring 2027 course list (its courses are not on CUNYfirst yet, so they show temporary numbers PSY-01 to PSY-64)

Stars, checklist ticks and calendar settings are saved in your own browser only.
